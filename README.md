# LET ME COOK

**Your brain is brilliant. Your prompts are about to catch up.**

*The brain-dump-to-brilliance AI thinking skill.*

LET ME COOK helps you turn scattered thoughts into clear, challenged, execution-ready prompts, briefs, creative strategies, project plans, and AI agent specifications. You bring the chaos. AI asks the right questions. Together, you build the blueprint.

Created by **Penelope Sloan Creative**, informed by the Soul to Success strategic approach.

## Get started for free

1. Download [`SKILL.md`](./SKILL.md).
2. Attach or paste it into your preferred LLM's instructions or project context and ask it to follow the skill. Native skill or slash-command installation varies by platform.
3. Type `/let-me-cook` (or say **let me cook**) and start talking, typing, or pasting your ideas.
4. The assistant stays in listening mode until you say **DONE WHIPPIN**.
5. Ask it to **GRILL ME**, **SHOW THE RECIPE**, or **PLATE IT** when ready.

See [QUICKSTART.md](./QUICKSTART.md) for more.

## What's on the menu?

| Command | What it does |
| --- | --- |
| `/let-me-cook` | Start an uninterrupted brain dump |
| `DONE WHIPPIN` | End the dump and start decoding |
| `SIDE DISH:` | Capture a tangent without derailing the main idea |
| `LET IT MARINATE` | Park a promising tangent for later |
| `GRILL ME` | Get strategic, challenging follow-up questions |
| `GO DEEPER` | Investigate risks, assumptions, and opportunities |
| `SHOW THE RECIPE` | Organize the idea into a structured blueprint |
| `PLATE IT` | Generate a useful, ready-to-use output |
| `MAKE IT A PROMPT` | Turn the plan into an LLM prompt |
| `MAKE IT AN AGENT` | Produce an agent specification |
| `PRESSURE TEST` | Critically evaluate the plan |

The commands work as **plain-language instructions** even where native slash commands are not supported.
